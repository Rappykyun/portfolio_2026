# Portfolio

This context defines the language used to present the portfolio and its projects to recruiters and hiring managers.

## Language

**Project case study**:
A structured explanation of a project covering its context, the author's role, what was built, honest status, and supporting evidence.
_Avoid_: project page when referring to the full story rather than the route itself.

**Featured project**:
A project promoted on the homepage because it best demonstrates the author's range and experience.
_Avoid_: production project unless real production use is confirmed.

**Evidence screenshot**:
A real captured image that demonstrates a project's interface or result.
_Avoid_: placeholder, mockup, or skeleton when describing final evidence.

**Demo**:
A link that lets someone inspect or try a project without claiming that the project is used in production.
_Avoid_: live site when production use is not confirmed.

**Project status**:
An honest label such as Internship Project, Thesis Project, Capstone Project, Prototype, or Deployed that describes how a project was made or used.
_Avoid_: implying production adoption when it did not happen.
